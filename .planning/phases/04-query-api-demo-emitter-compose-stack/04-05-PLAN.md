<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Compose env -> container | ClickHouse credentials cross from the host/Compose environment into the tracer container at runtime; they must never be committed into the image or compose file. |
| published host ports -> container | :4317/:4318/:8080 are published to the host; on a shared host these are reachable by anything that can reach the host. Auth is descoped (CONTEXT). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-16 | Information Disclosure | ClickHouse creds in compose/image | mitigate | Creds via `CLICKHOUSE_*` runtime env only; no password literal in any committed docker/ file (grep-gated in Task 1 + Task 2 verify). Mirrors ClickHouseConfig.fromEnv (no secret default in code, T-02-02). |
| T-04-17 | Tampering | base image / package provenance | mitigate | `eclipse-temurin:21-jre` and `clickhouse/clickhouse-server:26.3` are pinned official images (no `:latest`); no third-party packages installed in the Dockerfiles. |
| T-04-18 | Spoofing/Elevation | published unauthenticated ports on a shared host | accept (descoped) | Auth is OUT of scope for Phase 4 (CONTEXT); the stack targets single-team local/self-hosted use (REQUIREMENTS out-of-scope: auth/multi-tenancy). A later milestone adds the transport-agnostic validator and/or binds ports to localhost. Documented, not planned here. |
| T-04-19 | DoS | seeder flood on cold up | accept | Seeder is one-shot (`restart: "no"`) with an operator-bounded DEMO_RUNS; the receiver's Phase-3 backpressure protects the pipeline. |
| T-04-SC | Tampering | image/package installs | mitigate | Only pinned official base images; no npm/pip/cargo/apt third-party installs. No `[ASSUMED]`/`[SUS]` packages. |
</threat_model>
