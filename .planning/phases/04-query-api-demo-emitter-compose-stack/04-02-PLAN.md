    - True root: parentSpanId == "" maps to parentId = null (the run root).
    - Late/out-of-order: assembly is a set operation over the full list (associateBy spanId); never assumes the first span is the root; ordering metadata comes from timestamp, not arrival order.

    - Edges: one DagEdge(from = parentId, to = id) per node whose parentId is non-null (incl. synthetic-root edges); never an edge to a dropped node.
    - Subtree cost roll-up (SC2): subtreeCostUsd on each node = sum of its own costUsd (treat null as 0) + all descendants' costUsd, via a post-order DFS over the children-adjacency built from edges, guarded by a visited set so a malformed/self-referential graph cannot recurse unbounded. Orphan subtree costs roll up INTO the synthetic root, not into the void.
    - DTOs are immutable @Serializable val data classes; costUsd?/subtreeCostUsd? stay nullable (emit JSON null when unmeasured).
  </behavior>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP query param → RunFilter | Untrusted query-string values are coerced and bounded in `RunListMapper` BEFORE reaching the repository. This is the in-JVM validation seam; the HTTP boundary itself is crossed in Plan 04. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | cost/date param parsing in RunListMapper | mitigate | Parse `costMin/Max` with `toDoubleOrNull()` + `Double.isFinite()` (reject NaN/Inf); parse dates with `Instant.parse` (ISO-8601). Malformed input → typed bad-request, never a malformed RunFilter. Values still bound as `{name:Type}` placeholders downstream (T-02-06). |
| T-04-04 | DoS | unbounded `limit` / negative `offset` | mitigate | `paging()` clamps `limit` to MAX_LIMIT = 500 and floors `offset` at 0 BEFORE the value reaches the paginated `listRuns` (resolves Plan-01 hand-off T-04-02). |
| T-04-05 | DoS | huge trace DAG / malformed (cyclic) graph in roll-up | mitigate | DagAssembler is a single O(n) pass; `rollUpCosts` is cycle-guarded with a visited set (no unbounded recursion). The Phase-2 14-day TTL bounds per-run span volume. |
| T-04-06 | Information Disclosure | DAG/run DTOs leaking internal detail | accept | DTOs expose only agent-debugging fields (ids, costs, tokens, status, agent/skill names) — no stack traces, no DB internals, no secrets. Read-only surface; auth descoped per CONTEXT. |
| T-04-SC | Tampering | dependency installs | mitigate | No new packages in this plan (consumes Plan-01's first-party JSON deps). No `[ASSUMED]`/`[SUS]` installs. |
</threat_model>
